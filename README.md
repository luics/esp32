# 摩斯电报机

* 开发环境：Codex + VSCode + ESP-IDF（iot 开发框架），主要代码是 C/C++
* 硬件：ESP32-C6-Zero 开发板、按钮、OLED 显示器、小喇叭、面包板、跳线
    * 淘宝上搜索“ESP32-C6-Zero-Basic-Kit”，包含所有用到的硬件
* 仿真：Wokwi
* 耗时：从零做到[可用状态](https://github.com/luics/esp32/commit/1f5916c1293f63cfb9cb4fd593e573d0fa2a4800)，学习 ESP32 基础知识和开发环境大概 8h，开发调试 4h
